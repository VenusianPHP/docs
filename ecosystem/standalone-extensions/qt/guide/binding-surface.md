# Binding surface

Classes, enums and functions ext-qt binds, each one Qt call under its native name and signature; C++ scopes as PHP namespaces; Qt's value classes as PHP value objects.

## Overview

Scope: calls that create the application, pump Qt's event dispatcher, sleep with a budget, wake a sleep, open and close windows, build menus, lay widgets out ([layout](/docs/{{version}}/ecosystem/standalone-extensions/qt/guide/layout-and-geometry)), style them, drive the common controls, show images and GL and Vulkan surfaces, play video ([video](/docs/{{version}}/ecosystem/standalone-extensions/qt/guide/video)). Stubs = source of truth; `tests/SurfaceTest.php` fails if a stub declaration is missing from the build.[^stubs]

Naming and shapes, all fixed:

* Class = Qt class name, global namespace. Method = Qt method name, Qt's parameters in Qt's order with Qt's defaults. Static stays static.
* Nested C++ scope = PHP namespace: `Qt::TimerType` → `Qt\TimerType`, `QMetaObject::Connection` → `QMetaObject\Connection`, `QTextEdit::ExtraSelection` → `QTextEdit\ExtraSelection`.
* Enum = backed int enum, cases SCREAMING_SNAKE of the enumerator (`WaitForMoreEvents` → `WAIT_FOR_MORE_EVENTS`). QFlags params = `Enum|int`. Flags Qt spells as two enums (`QUrl::FormattingOptions`) are an int with the class's constants.
* Qt's value classes are PHP value objects holding a copy: `QPoint`, `QPointF`, `QSize`, `QRect`, `QDate`, `QKeySequence`, `QUrl`, `QByteArray`, `QColor`, `QBrush`, `QFont`, `QPixmap`, `QImage`, the text values. Never arrays or strings.
* An overload set binds the overload the native name keeps; overloads that differ by a trailing argument are one method with an optional parameter (`processEvents($flags, ?$maxtime)`, `start(?$msec)`).
* A C++ abstract class is `abstract`; a constructor only Qt calls is private; objects Qt returns are boxed, never constructed. A native nullptr is `null`.
* Stub file names follow Qt headers (`qnamespace.stub.php` for `Qt::`): the Mac volume is case-insensitive, so `qt.stub.php` and `Qt.stub.php` would collide.

Generated enums: `scripts/gen-enum.php <header> <enum> <scope> <PHP enum> [prefix]` writes the stub cases and `src/checks/<Scope>_<Enum>.inc`, one `static_assert` per case, compiled into `src/qt.cpp`, so each build proves the values against its own Qt. A member newer than the 6.4 floor is checked under `#if QT_VERSION >= QT_VERSION_CHECK(…)` (`QEvent::DevicePixelRatioChange` 6.6, the child and parent window events 6.7, `Qt::NoTitleBarBackgroundHint` 6.9, `Qt::Key_micro` 6.7, `Qt::Key_Keyboard` 6.10, `Qt::RangeModelDataRole` / `StandardItemFlagsRole` / `FileInfoRole` 6.10, `Qt::RangeModelAdapterRole` 6.11). Short enums are hand-written with a `static_assert` beside their registration.

Behaviour confirmed on both platforms: macOS (cocoa) makes the process a regular app on construction (Dock icon); Qt has no call to withdraw it. Linux: the app connects to the display server (`xcb` through XWayland on the Pi until `qt6-wayland` is installed); the taskbar lists windows, not processes.
