# Binding surface

Classes, enums and constants ext-appkit binds, each method one AppKit, Foundation, Core Foundation or Core Graphics call under its native name and signature.

## Overview

Scope: start AppKit, present/withdraw app from OS, pump events, sleep with a budget, wake a sleep, windows (modes, screens, display modes and capture, full screen, levels), views and layers, partial redraw, display-link pacing, OpenGL views, layout, controls, text, tables, observers, video, input events, game controllers, power assertions, menus. Stubs = source of truth; `tests/SurfaceTest.php` fails if a stub declaration is missing from the build.[^stubs]

Each method = one native call. Toolkit behaviour passes through: nil → `null`, NO → `false`, clamps, error codes, AppKit exceptions (as `AppKitException`). Refusals only where a probe shows the call crashes ([errors and threads](/docs/{{version}}/ecosystem/standalone-extensions/appkit/architecture/errors-and-threads)).

Naming, all fixed:

* Class = native class name, global namespace (`NSApplication`, `CFRunLoop`).
* ObjC selector = method named by joining selector parts, later parts capitalised: `nextEventMatchingMask:untilDate:inMode:dequeue:` → `nextEventMatchingMaskUntilDateInModeDequeue()`. Class methods static. Parameters in native order.
* CF/CG function on a type = method with type prefix dropped: `CFRunLoopAddSource` → `CFRunLoop::addSource()`, `CMTimeMakeWithSeconds` → `CMTime::makeWithSeconds()`. Create/Get functions static. A `CFAllocatorRef` parameter = `?CFAllocator` (null = default).
* NS_ENUM / CF enum = backed int enum, prefix dropped, cases SCREAMING_SNAKE (`NSApplicationActivationPolicy::REGULAR`, `NSRequestUserAttentionType::CRITICAL_REQUEST`). Values from SDK headers.[^sdk]
* NS_OPTIONS param = `Enum|int`: pass a case or OR'd ints (`NSEventMask::ANY` = -1 = NSUIntegerMax).
* Enum return with values outside the header (private event types) = `Enum|int`.
* Void selector → `void`. BOOL → `bool`. NSInteger/NSUInteger → `int`. NSTimeInterval/CGFloat → `float`.
* C scalar out-parameter = by-reference PHP param in native position. ObjC struct out-parameter = returned array. CGError / IOReturn = returned `int`.
* Struct = `final` value class, every field a required constructor argument (`new NSRect(0.0, 0.0, 0.0, 0.0)`).
* Global C/ObjC constants = PHP global constants, same name, value read from framework at MINIT.
