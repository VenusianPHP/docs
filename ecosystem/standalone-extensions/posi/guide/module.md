# Module

Scope, file layout, module globals, load order, errno and argument conventions.

## Scope

POSIX calls, 1:1, plain C on Zend API. No Zephir, no FFI. Linux + macOS; Windows excluded in `composer.json` `php-ext`.

POSIX only. OS-specific event APIs stay out: epoll, eventfd, timerfd, signalfd (Linux) live in ext-epoll; kqueue (macOS/BSD) in ext-kqueue. Exception that stays: Linux `termios2`/`BOTHER` inside `posi_set_baud_rate()`, and `ppoll()` on Linux with `poll()` fallback on macOS, both behind POSIX-shaped functions. See [termios](/docs/{{version}}/ecosystem/standalone-extensions/posi/api/termios), [descriptors](/docs/{{version}}/ecosystem/standalone-extensions/posi/api/descriptors-and-paths).

## Files

| File | Holds |
|---|---|
| `posi.c` | descriptors, paths, `fcntl`, `ioctl`, `ppoll`, `fdopen`, wait, native buffers, `posi_errno`, MINIT constants, module entry |
| `posi_termios.c` | termios functions, `posi_set_baud_rate`; declared in `php_posi.h`, function table in `posi.c` |
| `php_posi.h` | version, module globals, `POSI_RECORD_ERRNO`, `POSI_ARG_INT` |
| `posi.stub.php` | every function and `#ifdef`-guarded constant; source of `posi_arginfo.h` |
| `posi_arginfo.h` | generated by gen_stub; never hand-edited. See [build](/docs/{{version}}/ecosystem/standalone-extensions/posi/runbooks/build-install-test) |
| `config.m4` | checks `fcntl.h poll.h termios.h sys/uio.h sys/wait.h`; `PHP_ADD_EXTENSION_DEP([posi], [posix])` |

## Module globals

`last_errno` (int) and `allocations` (HashTable address → size). GINIT zeroes both, updates TSRM cache under ZTS. RINIT resets `last_errno`, inits `allocations`, updates TSRM cache. RSHUTDOWN `efree`s every live allocation, destroys table.[^header][^posi-c]

## Load order

`posi_deps`: `ZEND_MOD_REQUIRED("posix")`; `ZEND_MOD_OPTIONAL` pcntl, sockets, kqueue. Required: `posix_getuid()`/`posix_setuid()` come from ext/posix under same names, so posi never defines them. Optional deps only order loading so shared constants register once. See [constants](/docs/{{version}}/ecosystem/standalone-extensions/posi/api/constants).[^posi-c]

## Conventions

- Failure = C's -1 or false. `POSI_RECORD_ERRNO()` saves `errno` into `last_errno` right after the failing call; `posi_errno()` returns it. Successful calls leave it alone.
- `POSI_ARG_INT`: `zend_long` → `int` with `ZEND_LONG_EXCEEDS_INT` check; out of range → `ValueError` naming the argument. Same rule for modes (0–0o7777), uid/gid (-1–UINT32_MAX, -1 = unchanged), lengths (≥ 0, ≤ data), `ppoll` events (0–SHRT_MAX).
- By-ref outputs through `ZEND_TRY_ASSIGN_REF_*`, so typed references work.
- Buffers read from C: `zend_string_alloc`, then `posi_string_finish()` truncates to bytes used.
- NTS + ZTS both supported: state only in module globals.
