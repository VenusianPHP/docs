# Processes

posix_wait, posix_waitpid and the sys/wait.h status macros.

## Functions

| Function | C | Returns |
|---|---|---|
| `posix_wait(?int &$status = null)` | `wait` | pid, or -1 |
| `posix_waitpid(int $pid, ?int &$status = null, int $options = 0)` | `waitpid` | pid, 0 under `WNOHANG` with nothing ready, or -1 |
| `posix_wifexited`, `posix_wifsignaled`, `posix_wifstopped`, `posix_wifcontinued` | `WIF*` | bool |
| `posix_wexitstatus`, `posix_wtermsig`, `posix_wstopsig` | `W*` | int |

`$status` filled only when a child reported (pid > 0); untouched on -1 and on `WNOHANG`'s 0. Macros generated by `POSI_STATUS_FUNCTION`; `posix_wifcontinued` exists only where `WIFCONTINUED` does (stub `#ifdef`).[^posi-c]

Status words are OS-encoded, and signal numbers differ by OS (`SIGSTOP` 19 Linux, 17 macOS). Tests produce real statuses from child processes, never hand-built ints.

Options: `WNOHANG`, `WUNTRACED`, `WCONTINUED` — registered only when ext/pcntl hasn't. See [constants](/docs/{{version}}/ecosystem/standalone-extensions/posi/api/constants).

[^posi-c]: posi.c
