# Changelog

What changed in this package, newest first.

### 2026-10-12

* **0.10.2 — select ceiling by descriptor number**: `SelectDriver::watch()` probes each stream and refuses a descriptor numbered past FD_SETSIZE; `wait()` throws on a `stream_select` failure other than `EINTR`. 0.10.1 counted watched streams only, admitted descriptor 1024+ under load past 1024 connections, and spun at 100% CPU serving no one. See [loop](/docs/{{version}}/ecosystem/laravel-packages/forte/architecture/loop).
* **0.10.1 — coalesced writes**: `Http\Connection::send()` queues; one flush per connection per loop tick via the new `LoopInterface::futureTick()`. 0.10.0 wrote every frame immediately and fell ~25% behind Reverb at 950 connections on a 1 vCPU box; coalesced, it handles ~49% more events than Reverb on the same box. See [transport](/docs/{{version}}/ecosystem/laravel-packages/forte/architecture/transport), [loop](/docs/{{version}}/ecosystem/laravel-packages/forte/architecture/loop).
* **Creation**: Bundle created from the repository history (Reverb fork at `74c8c40` through the ReactPHP removal): [overview](/docs/{{version}}/ecosystem/laravel-packages/forte/guide/overview), [loop](/docs/{{version}}/ecosystem/laravel-packages/forte/architecture/loop), [transport](/docs/{{version}}/ecosystem/laravel-packages/forte/architecture/transport), [promises](/docs/{{version}}/ecosystem/laravel-packages/forte/architecture/promises), [scaling](/docs/{{version}}/ecosystem/laravel-packages/forte/architecture/scaling), [reverb compatibility](/docs/{{version}}/ecosystem/laravel-packages/forte/guides/reverb-compatibility), [testing](/docs/{{version}}/ecosystem/laravel-packages/forte/runbooks/testing).
* **ReactPHP removed**: `react/promise` and `evenement/evenement` left `require`; `ratchet/pawl`, `react/async`, `react/http`, `react/promise-timer` left `require-dev`. Forte's own `Promise`/`Deferred` replace React's; the suite's WebSocket and HTTP clients run on Forte's loop. See [promises](/docs/{{version}}/ecosystem/laravel-packages/forte/architecture/promises), [testing](/docs/{{version}}/ecosystem/laravel-packages/forte/runbooks/testing).
* **Reverb config adopted**: an app's `config/reverb.php` drives Forte until `config/forte.php` is published. See [reverb compatibility](/docs/{{version}}/ecosystem/laravel-packages/forte/guides/reverb-compatibility).
* **Pulse recorder aliases**: `Laravel\Reverb\Pulse\Recorders\ReverbConnections` and `ReverbMessages` resolve to Forte's recorders when laravel/reverb is gone. See [reverb compatibility](/docs/{{version}}/ecosystem/laravel-packages/forte/guides/reverb-compatibility).
