# Changelog

What changed in this package, newest first.

### 2026-10-04
* **New**: [GIBS](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/gibs) — WMTS (capabilities, tiles, vector tiles, domains; RESTful or KVP; tile-grid math), WMS 1.1.1/1.3.0, TWMS, colour maps, legends, layer and vector metadata, vector styles with an expression evaluator. Moves from [deferred](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/deferred/deferred-nasa-apis) to core in [API coverage](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/architecture/stargazer-api-coverage). Version 0.10.1.
* **Update**: [Async lane](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/architecture/stargazer-async-lane) — XML and byte payloads, per-request timeouts.

### 2026-10-02
* **Update**: [APOD](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/apod) — `NasaURL::APOD` moves to science.nasa.gov's `wp-json/wp/v2/apod-basic` (api.nasa.gov APOD archived 2026-12-01); no `api_key`. `date()` addresses `/YYMMDD`; `range($start, $end)` sends `date_from`/`date_to`/`per_page`, oldest first, ≤100 days; `count()` = consecutive days from a random page. `$thumbs` and `service_version` gone; `AstronomyPicture` gains `permalink`, `alt`, a screen-sized `url`, mp4 `url` on video days, plain-text explanation and credit. [Architecture](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/architecture/stargazer-request-architecture), [API coverage](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/architecture/stargazer-api-coverage) follow.
* **Update**: [TechTransfer](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/techtransfer) — host line corrected to `technology.nasa.gov`, no `api_key`.
* **Update**: [DONKI](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/donki) — `NasaURL::DONKI` moves to CCMC's `https://ccmc.gsfc.nasa.gov/DONKI-API/get` (api.nasa.gov/DONKI now 301s to a news page); no `api_key`. [Architecture](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/architecture/stargazer-request-architecture), [API coverage](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/architecture/stargazer-api-coverage) follow.
* **Update**: 0.10 — requires `venusian-voyager/*` ^0.10.0 ([index](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/overview)); `StargazerException::status()` carries the failed response's HTTP status ([async lane](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/architecture/stargazer-async-lane)).

### 2026-09-23
* **Update**: [Async lane](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/architecture/stargazer-async-lane) — `async()` returns a loop promise of the `get()` DTOs; rejects with `StargazerException`; `render()`/`fetch()` return `Promise<Response>`. Envelope pattern concept deleted; mail classes gone. Family concepts, [API coverage](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/architecture/stargazer-api-coverage), [getting started](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/guide/getting-started-venusian-stargazer) follow. `nasa()` replaces the `NASA` MagicAlias.

### 2026-09-04
* **Update**: Envelope wrap — all nine core families are exemplars. [DONKI](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/donki), [NeoWs](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/neows), [TLE](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/tle), [TechTransfer](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/techtransfer), [APOD](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/apod), [EONET](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/eonet), [EPIC](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/epic), [InSight](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/insight), and [Image and Video Library](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/image-and-video-library) name Arrived/Failed (plus APOD/EPIC `renderAsync` and Image Library `fetchAsync`). [Getting started](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/guide/getting-started-venusian-stargazer) now points at `src/MagicAliases/NASA.php` and the `'nasa'` accessor. Deferred stubs unchanged.
* **Update**: [Image and Video Library](/docs/{{version}}/ecosystem/other-packages/venusian-stargazer/core-api-families/image-and-video-library) re-plated onto the hydrator/envelope lanes — `ImageLibraryArrived` / `ImageLibraryFailed` on search, asset, metadata, and captions; `ImageLocation::fetchAsync()` follows the `{ location }` pointer as `ImageSidecarReady` / `ImageSidecarFailed`; `NASA::imageLibrary()` is on the MagicAlias `@method` block.
* **Creation**: Async envelope pattern (concept since deleted) — two-lane hydrator/envelope recipe with typed `*Arrived`/`*Failed` mail; APOD, InSight, EONET, EPIC converted as exemplars (incl. `EpicImage::renderAsync()` link-follow); test harness rebuilt on `IOPoolDock` + `FakeCurlDriver`.
