# Physics

PhysicsDriver contract, PhysicsBridge step order, the php driver (Box2D/Godot ports), the box2d driver over ext-box2d, physics nodes and shapes.

## Physics

Godot 2D physics nodes over a swappable driver (Godot's PhysicsServer2D split). Contract `Terran\Physics\PhysicsDriver`, int handles, value classes (`BodyState`, `BodyParams`, `ShapeDef`, `AreaParams`, `StepEvents`, queries/hits). `PhysicsManager` (`terran.physics`): `extend(name, Closure)`; `auto` = first extended, else `box2d` when ext-box2d is loaded, else `php`.

World: 7th-9th args driver (default `PhpDriver`), gravity (0, 980), debug. `PhysicsBridge` owns node↔driver: bodies created on going live, destroyed on removal; per step inside `GameLoop::duringStep()` (after every `physicsProcess`): param/shape/exception sync by cheap signatures (shape rebuild only on change; rounded body scale), teleport when node pose or velocity differs from last write (wakes body), kinematic target → velocity (Animatable with `syncToPhysics`, frozen-kinematic Rigid), `integrateForces()` with `AreaEffects` totals, driver step, rigid write-back (parent-local), events → Interrupts (contacts, areas, sleeps), every RayCast2D casts. Picking after UI: pickable nodes under pointer, topmost first.

php driver (`Terran\Physics\Php`): convex = ≤8 points + radius (circle 1, capsule/segment 2); Box2D v3.1.1 ports: `Collide` (circles, polygon-circle, SAT+clip polygons), `Gjk` (distance, segment distance, shape cast), `Geometry` mass (a body of lines only: length-weighted rods, m·L²/12 each). `Space::step`: place moved shapes, insertion-sorted x sweep (+half-planes pair with all), area overlaps (diffed → `AreaEvent`), contacts (persistent by part pair, impulses carried by point id, one-way filter, Godot material combine), wake islands (union-find; moving kinematic/static-with-velocity wakes), integrate (gravity/damp via `AreaEffects`), `Solver` (16 iterations; friction then normal; 2-point block solver for normal and split-impulse; speculative 1.2 px; split impulse slop 0.3, 20 %/step; restitution pass > 50 px/s), integrate positions, CCD sweep (RAY centre / SHAPE conservative advancement, stop a slop short), sleep islands (2 px/s, 8°/s, 0.5 s). `Queries::motion` = Godot body_test_motion (4 recovery passes at 40 %, sweep, rest info at unsafe point).

Nodes `Terran\Scenes\Physics`: `CollisionObject2D` (layers, picking Interrupts), `PhysicsBody2D` (exceptions, `moveAndCollide`/`testMove`), `StaticBody2D` (constant velocity conveys), `AnimatableBody2D`, `RigidBody2D` (props written back, contact Interrupts capped by `maxContactsReported`, `integrateForces`), `CharacterBody2D` (Godot 4.3 move_and_slide port), `Area2D`, `CollisionShape2D`, `CollisionPolygon2D` (ear clip + merge to ≤8-corner convex pieces; SEGMENTS static only), `RayCast2D`. Shapes `Terran\Physics\Shapes` (`PhysicsShape` base; scale baked into points; round shapes refuse uneven scale; one-way axis = shape node +y).

box2d driver (`Terran\Physics\Box2D`): `Box2DDriver` keeps a never-stepped `PhpDriver('box2d')` mirror (handles, checks, geometry, mass, area overlaps, queries) and a Box2D world per space (`Box2DSpace`): 32 px/m, 16 sub-steps at contact hertz ¼ of the sub-step rate, serial, no speed cap; Box2D's mass pass from the shapes runs before the mirror's mass goes in (continuous collision needs its extent). Callbacks: custom filter = php pair rule (layer OR, exceptions), refilter by flipping category bit 4; pre-solve = one-way; friction/restitution = php material combine (rough/absorbent as material id bits). Shapes: convex → circle/capsule/rounded polygon, a line (2 points, radius 0) → capsule of `Box2DShapes::SKIN` (0.005 m = 0.16 px; Box2D has no segment–segment collider), segments → segments (a piece ≤ 2·SKIN → that capsule; Box2D asserts on shorter), boundary → 10⁵ px box, separation ray → none; areas = static bodies with sensor shapes; disabled = empty filter. Static with velocity = kinematic, put back after the step. Step: area overlaps (`b2World_OverlapAABB` candidates → mirror `Space::areaEvents`), area gravity as a force + damping, constant forces, `b2World_Step`, move events → mirror + sleep/wake, contact begin/end per Terran shape pair. Queries: php `Queries` over a mirror view of Box2D broadphase candidates + planes + separation rays + own shapes.

Measured (xdebug off), 100 boxes + 40 floor tiles through nodes, per step awake / asleep: Mac php84 NTS php 4.95 / 1.77 ms, box2d 1.69 / 1.37 ms; Pi ZTS php 8.32 / 3.02 ms, box2d 2.83 / 2.56 ms. Driver alone (Mac): php 3.24 ms awake, box2d 0.16 ms.
